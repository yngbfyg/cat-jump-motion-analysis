# Original 2023 research documents

Historical school project **Кошкоскок**, by **Margarita Trott and Irina Khlebina**.

The optional source-upload archive contains:
- `2023-research-instructions-ru.docx` — original Russian step-by-step manual with embedded screenshots: filming, DeepLabCut Model Zoo, HSV-colored square calibration and plotting.
- `2023-research-presentation-ru.pptx` — original seven-slide Russian research presentation.

The names are normalized for GitHub; the files' bytes and content are unchanged. These original binary files need to be uploaded separately to appear in this folder.

For a readable English summary of the original manual, see [Getting started](../GETTING_STARTED.md). The original graphs remain historical exploratory results, not independently verified physical measurements.

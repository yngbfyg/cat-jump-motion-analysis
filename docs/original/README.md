# Original 2023 research documents

Historical school project **Кошкоскок**, by **Margarita Trott and Irina Khlebina**.

This repository includes the unmodified original documents:
- [Original Russian step-by-step manual](2023-research-instructions-ru.docx) — filming, DeepLabCut Model Zoo, HSV-colored square calibration, and plotting, with screenshots.
- [Original Russian research presentation](2023-research-presentation-ru.pptx) — seven slides describing the 2023 project.

Only the filenames were normalized for GitHub; the documents themselves were preserved unchanged.

For a readable English summary of the original manual, see [Getting started](../GETTING_STARTED.md). The original graphs remain historical exploratory results, not independently verified physical measurements.

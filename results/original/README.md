# Original experimental figures (2023)

These are **all 27 original plots** preserved from the school project *Cat Jump Motion Analysis / Кошкоскок* by Margarita Trott and Irina Khlebina.
The images are the original exported plots, without redrawing, replacing or adjusting their plotted values.

**Interpretation note:** the position–time, velocity and acceleration charts are **historical exploratory outputs** from the original project. The retained data cannot independently establish a reliable mapping between filtered tracked points and their original frame times. Therefore, their derived velocity/acceleration curves should **not** be treated as independently validated measurements.

The three main trajectory plots also appear on the main repository page.
